Building this blog

Nov 9, 2026

This site is deliberately boring: plain HTML and one CSS file. No build step, no framework, no dependencies.

Why so simple?

  • Every page is a file you can open and read.
  • Deploying means copying a folder anywhere.
  • Nothing breaks when a dependency updates.

Adding a post

Copy an existing file in posts/, change the title and text, then add a link to it in index.html. That's the whole workflow.

The best publishing system is the one you'll actually use.
